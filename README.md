## 📖 About The Game
**UMBRA** is a fast-paced, cooperative action-platformer where two players share a single keyboard to survive a hostile environment. 

* 🔥 **Pyre (The Firebearer):** Immune to lava. Casts a dynamic shadow controlled by a moving sun.
* 🌑 **Umbra (The Shadowrunner):** Cannot touch lava, but can safely traverse Pyre's shadow when it aligns correctly.

## ✨ Key Features
* 🌞 **Dynamic Shadow Mechanics:** The environment shifts with the sun's continuous cycle. Use "Shadow Lock" to freeze paths.
* 🤝 **Always-On-Tail Co-op:** Move simultaneously. Chain multiple freezes across massive lava rivers using Crystal Footholds.
* ⌨️ **Shared Screen Local Co-op:** Designed specifically for two players sharing one keyboard and screen.
* 🗺️ **Two Complete Realms:**
  * *Level 1: The Volcanic Temple* - Master the tail-escort and freeze mechanics across 6 distinct gates.
  * *Level 2: The Obsidian Citadel* - Survive sinking basalt islands, magma geysers, dual-seal locks, and defeat **Ignis-Sol, The Eclipse Colossus**.
* 🎨 **Zero External Assets:** Features realistic procedural flowing lava shaders and a Web Audio API synthesizer built entirely from scratch.
